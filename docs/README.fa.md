# مستندسازی گفتگو

این برنامه برای ویندوز است و دو مسیر دریافت گفتگو دارد: گرفتن بخش انتخابی چت از
مرورگر، یا واردکردن خروجی رسمی پیام‌رسان. تبدیل فایل صوتی مستقل هم در گزینهٔ ۱۲
قرار دارد و به چت وابسته نیست.

## نصب

پایتون ۳٫۱۳ را نصب کنید. سپس در پوشهٔ پروژه `setup.cmd` را اجرا کنید و بعد
`Chat Documentation.cmd` را باز کنید. نصب اولیه به اینترنت نیاز دارد.

## شروع

- گزینهٔ ۱: گزارش جدید؛ انتخاب پیام‌رسان و مسیر مرورگر یا خروجی رسمی.
- گزینهٔ ۲: ادامهٔ گزارش ذخیره‌شده و بررسی مرحلهٔ ناتمام.
- گزینهٔ ۹: تعمیر مرحله‌ای گزارش، با نگهداری نسخهٔ قبلی.
- گزینهٔ ۱۲: تبدیل ویس یا فایل صوتی مستقل به متن.

واتساپ: خروجی `WITH MEDIA` را انتخاب کنید. تلگرام دسکتاپ: خروجی یک چت با فرمت
JSON و فایل‌های همراه را انتخاب کنید. خروجی HTML تلگرام پشتیبانی نمی‌شود.

تبدیل صوت با Whisper روی سیستم یا GPU کولب انجام می‌شود. خروجی خام بدون اتصال
مدل زبانی در دسترس است. برای فعال‌کردن اصلاح متن، گزینهٔ ۵ را بزنید و روش اتصال را
انتخاب کنید: حساب ChatGPT یا کلید OpenAI API. کلید به‌صورت مخفی دریافت و با رمزگذاری
ویندوز ذخیره می‌شود؛ استفادهٔ API تابع اعتبار و تعرفهٔ حساب API شماست. برنامه اتصال
را بررسی می‌کند و در صورت نیاز ورود را باز می‌کند. سپس مدل را انتخاب کنید یا اینتر
بزنید؛ تنظیمات خودکار ذخیره و فعال می‌شوند. هیچ فایل تنظیماتی را لازم نیست دستی
تغییر بدهید. گزینهٔ ۵ امکان تغییر مدل و خاموش‌کردن اصلاح متن را هم دارد.

متن‌های ترمینال انگلیسی‌اند؛ اکسل از متن و عنوان فارسی پشتیبانی می‌کند.
صوت‌های مستقل در `Outputs/Audio` ذخیره می‌شوند. فایل `Raw_Transcript.txt` متن
خام است و `Readable_Transcript.txt` فقط پس از تکمیل اصلاح متن ساخته می‌شود.

گزارش کامل‌شده به معنی تضمین استخراج تمام تاریخچه نیست. نام‌های نامشخص، فایل‌های
ناقص، تاریخ‌های تأییدنشده و عبارت‌های مبهم را بررسی کنید. مدل می‌تواند کلمات،
نام‌ها و عددها را اشتباه بشنود؛ متن روان الزاماً متن درست نیست.

هیچ گفتگو، ویس، کلید، نشست ورود یا مدل دانلودشده‌ای در این مخزن نیست. داده‌های
واقعی را در issue و pull request عمومی قرار ندهید. برنامه هنوز آزمایشی است.
